## 🚀 Sobre mí

Frontend Developer con 2 años de experiencia en productos SaaS. Desde septiembre de 2024 trabajo en **Seeker Parking**, un SaaS de estacionamiento inteligente, donde soy responsable del frontend en un equipo con backend, QA y Product Management.

- Desarrollo la nueva plataforma que reemplaza al sistema legacy: panel administrativo y aplicación para clientes, con React, TypeScript, Next.js (App Router, SSR) y Vite.
- Implemento los flujos de registro y compra con React Hook Form y Zod, integrados con APIs REST.
- Construyo componentes reutilizables: tablas de datos, skeletons, inputs, selects con autocompletado y un recortador de imágenes.
- Mantengo el sistema legacy (HTML, CSS y jQuery) mientras avanza la migración.
